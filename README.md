# RotaSmart

## O que é o RotaSmart?

O **RotaSmart** é um protótipo acadêmico desenvolvido para a gestão simplificada de veículos. O projeto tem como objetivo demonstrar a aplicação de controle de acesso baseado no perfil do usuário (*Administrador* ou *Motorista*) em uma interface direta e objetiva.

Por se tratar de uma prova de conceito focada no controle de permissões e no gerenciamento de dados, o sistema não é um painel logístico completo ou dashboard, sendo estruturado nas seguintes páginas:

* **Página de Login e Cadastro**: Onde o usuário realiza o acesso ao sistema ou cria uma nova conta para utilizar a plataforma.
* **Página de Veículos**:
  * **Motoristas**: Têm permissão apenas para consultar a listagem dos veículos cadastrados na frota.
  * **Administradores**: Possuem acesso total para visualizar a lista, cadastrar novos veículos e remover registros existentes.
